# Emma Karimi Kinyua - Portfolio Website

A vibrant, modern portfolio website showcasing my professional journey as a Full Stack Software Engineer. Built with React, TypeScript, and Tailwind CSS, featuring a clean design with orange (#ff6b4a) and green (#10b981) accent colors that reflect my personality as a "Tech Girl".

## 🌟 Features

- **Hero Section**: Eye-catching introduction with profile image, tech stack highlights, and quick access to contact information
- **About Me**: Professional summary highlighting education, certifications, and technical expertise
- **Work Experience**: Detailed timeline of professional roles and achievements
- **Education**: Academic background and ALX Software Engineering certifications
- **Technical Skills**: Organized by category (Backend, Frontend, Databases, Tools & Platforms)
- **Projects Showcase**: Featured projects including:
  - Personal Portfolio Website
  - First Choice Mineral Feeds Ltd Corporate Website
  - ALX Backend Capstone Project
- **Contact Section**: Direct email integration with pre-filled Gmail compose window
- **Responsive Design**: Optimized for all screen sizes
- **Modern UI/UX**: Smooth animations, gradient effects, and hover interactions

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd portfolio-website
```

2. Install dependencies:
```bash
npm install
# or
pnpm install
```

3. Start the development server:
```bash
npm run dev
# or
pnpm dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
# or
pnpm build
```

The optimized production build will be in the `dist` directory.
